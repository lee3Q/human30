# 자극 엔진 옵션 I vs 옵션 II 비교

> **작성**: 2026-04-23, Opus 자율 세션 (SELF-1).
> **작성 근거**: `NEXT_v2.md` "30p와의 통합 가능성"에서 *"B 트랙 에이전트 산출물(opus·sonnet)에서 양 옵션 저울질 제출. 결정은 상규"* 명시.
> **입력 문서**: `02_자극엔진_opus.md` (비판·구조 층), `02_자극엔진_sonnet.md` (실행·외연 층).
> **경계**: **결정은 하지 않음.** 이상규가 결정. 본 문서는 양 옵션의 재료를 표로 정리하기만 함.

## 0. 한 줄 요약

| 구분 | 옵션 I (독립 제품) | 옵션 II (30p 내부 수렴) |
|---|---|---|
| 핵심 | 외부 서사 DB 별도 구축, 30p와 분리 | 30p 30명이 상규 자료의 해석자 역할 담당 |
| Opus 판정 | **강한 권장** | 30p 오염 위험, 강한 비권장 |
| Sonnet 판정 | **권장** | 단기 프로토타입 차용만 가능 |
| 양 에이전트 일치도 | **옵션 I 쪽 수렴** | 제한적 허용(단기) ~ 거부 |

## 1. 정의 비교 (두 문서에서 추출)

| 축 | 옵션 I (독립) | 옵션 II (수렴) |
|---|---|---|
| **핵심 메커니즘** | 상규 기록 × 외부 서사 원형 DB → 구조 매칭 | 30p의 30명이 상규 자료를 각자 해석 → 비상규적 해석 30개 |
| **입력 공간** | 외부 문학·신화·영화·경전·저속 텍스트 | 30p 4층 28표에서 굴러나온 캐릭터 어휘 |
| **어휘 저장소** | 카뮈·장자·카프카·헉슬리·보르헤스 등(이미 쓰인 은유 자산) | 30세 공대생 관점, 상규가 설계한 옵션 표 안의 어휘 |
| **낯섦의 원천** | 상규가 쓰지 않는 외부 어휘계로 번역 | 타인 30명 시선의 복수성 |
| **30p 정체성** | 유지 (자극 엔진과 무관) | 변형: "같은 자극 위 30명이 다르게 반응" → "상규를 30명이 해석" |

## 2. 장점 비교표

| 항목 | 옵션 I | 옵션 II |
|---|---|---|
| 어휘 밀도 | 문학 원형의 천 년 쌓인 은유 자산 사용 가능 | 30명 캐릭터 어휘로 제한 (20세 한국인 범위) |
| 낯섦 생성력 | 상규가 설계하지 않은 외부 어휘 → 놀람 확률 높음 | 상규가 이미 설계한 옵션 표 안 → 놀람 생성력 약함 |
| 30p 미학 보호 | 완전 분리로 30p 카페라떼 미학 오염 없음 | 해석 역할 투입 시 "동정·개입·미화 금지" 원칙 위반 |
| 사용 맥락 명확성 | 고고학자/자극엔진/30p 각자 경계 선명 | 30p 안에서 용도 중복, 혼동 가능 |
| 상규 외 2번 유저 가능성 | 일반 확장 가능 (자기 기록 있는 유사 체질) | 30p 인프라 상속 필요 → 확장 어려움 |
| 4월 30p 데드라인 영향 | 4월 중에는 설계만, 5월 이후 착수 → 분리 | 30p 일부로 포함 시 데드라인 일정과 경쟁 |

## 3. 단점 / 비용 비교표

| 항목 | 옵션 I | 옵션 II |
|---|---|---|
| 초기 구축 비용 | **외부 서사 DB 처음부터 구축** (10~50개 큐레이션) | **0** — 30p 인프라 즉시 재활용 |
| 미학 충돌 | 없음 | **큼** — 해석 장치 vs 카페라떼 미학(비해석) 직접 충돌 |
| 정체성 오염 위험 | 없음 | **큼** — 30명이 "상규 해석자"로 전락 |
| 상규 주의력 분산 | 4월 데드라인 동안 병렬 진행 시 위험 | 30p 안에서 처리 → 표면상 집중 유지 |
| 카피톤 위험 | "취향 추천 아님" 카피톤 (Spotify류) | 30p 복수성 원칙 유지하는 척 |
| 풀림 재실패 경로 위험 | 독립 제품 → 상용화 정당화 4층 쌓기 유혹 | 30p 내부 실험이라 상용화 유혹 약함 |

## 4. 수익·제품 가능성 (Opus 판정 기반)

| 축 | 옵션 I | 옵션 II |
|---|---|---|
| 한국어권 잠재 사용자 (Opus 추정) | 수천 명 이하(문학·철학 독서가 × 구조 독해 훈련자) | 30p 실험 대상(상규 본인 ~ 동료 지식인 소수) |
| 대중 타깃(MBTI류 대체) | **0** — 무겁고 발산, 공유 불가 | **0** — 30p 자체가 대중 도구 아님 |
| 상규 본인 전용 도구 성립 | **성립** — 53K 카톡+블로그+세션+30p 자산 보유자 | **성립** — 30p 안에서 실험 가능 |
| 상용화 정당성 | **약함** — Opus는 "본인 전용만 추천" | 해당 사항 없음(30p 자체가 공개물 아님) |

**공통 결론**: 두 문서 모두 **자극 엔진을 상규 본인 전용 도구로 프레이밍**하는 쪽을 지지. 상용화·서비스화 시 정당화 4층 쌓기 위험.

## 5. 실행 난이도

| 축 | 옵션 I | 옵션 II |
|---|---|---|
| DB 구축 | 필수, 초기 10~15개 → 확장 50개 목표 | 불필요 (30p 캐릭터 재활용) |
| 프롬프트 설계 | STEP 1(구조 추출) / STEP 2(매칭) / STEP 3(재기술) 3단 | 30명 캐릭터별 해석 프롬프트 30종 필요 |
| 인프라 | 신규 (프롬프트 + DB 텍스트 파일) | 재활용 (4층 28표, 시드 생성기) |
| 운영자 부담 | **중간** — 상규 1인 감당 가능 수준, DB 초기 큐레이션 Claude가 제안 → 상규 거부권 모델 | **낮음** — 기존 30p 워크플로에 탑재 |
| 4월 데드라인 병렬 가능성 | 병렬 시 30p 지장, 직렬(5월 이후) 권고 | 30p 일부로 처리 → 표면은 병렬 아님 |

## 6. 위험 구조

| 위험 | 옵션 I | 옵션 II |
|---|---|---|
| 거울 트랩 (DB 취향 필터로 수렴) | 큼 — 방어책 필수(비취향 70% 쿼터 등) | 30명 자체가 상규 설계물 → **거울 트랩 확률 매우 큼** |
| 환각/콜드리딩 | LLM이 만든 가짜 유사성 | 30명 해석이 상규가 이미 아는 언어로 수렴 |
| 풀림 재실패(정서 파트너화) | 피로 게이트 설계 없으면 위험 | 30p 자체가 정서 도구 아니라 덜 위험 |
| 30p 정체성 손상 | **없음** | **큼** — 30p = "같은 자극 30명 다른 반응"이 "30명이 상규 해석"으로 전환되는 구조적 변형 |
| 설계 오염 파급 | 한정적 | **30p 전체로 파급 가능** — 캐릭터 서술에 평론 습관 스며듦 |

## 7. Opus vs Sonnet 입장 요약

| 문서 | 옵션 I 판정 | 옵션 II 판정 | 세부 조건 |
|---|---|---|---|
| **Opus** (02_자극엔진_opus.md) | **강한 권장** | **비권장** | 단 옵션 I도 8개 필수 조건이 박힌 경우만. 본인 전용 도구 프레이밍 필수. 30p 4월 데드라인 후 착수. 고고학자 Step 4-5 완결 후 실측 기반으로 착수 정당화. |
| **Sonnet** (02_자극엔진_sonnet.md) | **권장** | **부분 차용만** | 프로토타입 초기 단계(서사 DB 구축 전)에서 30명 중 3~5명 관점으로 상규 기록 해석 돌려보고 놀람 판정. 놀람 없으면 옵션 I로 확정 이동. |

**수렴 지점**: 두 에이전트 모두 **옵션 I을 기본안으로, 옵션 II는 (부분 차용 or 거부) 입장.** 양측 모두 "30명 → 30 평론가 패널 전환" 위험 인지.

**갈라지는 지점**: Opus는 옵션 II를 구조적으로 **차단**. Sonnet은 옵션 II를 단기 프로토타입 용도로만 **제한 허용**.

## 8. 공통 전제 (두 문서 모두 명시)

1. 자극 엔진은 **상규 본인 전용 도구**로 프레이밍. 상용화·대중화 목표 제외.
2. 매칭 근거는 **원문 인용 필수**. 인용 없는 매칭은 할루시네이션 추정.
3. **"공명" 금지어**. 측정 불가능한 주관 단어는 설계 문서에서 배제.
4. 4월 30일 30p 데드라인 **침범 금지**. 자극 엔진 본격 착수는 5월 이후.
5. 발견 축 (α 예측 불가능성) 보장 위해 DB에 상규 **취향 바깥 텍스트 다수** 포함 필요.

## 9. 결정 시 이상규에게 필요한 추가 질문 (본 문서가 답하지 않는 부분)

결정은 상규가 내리되, 결정 전 자기 확인 체크리스트:

1. **시점**: 4월 30p 데드라인 후로 미뤄도 되는가? (병렬 vs 직렬)
2. **프레이밍**: 상규 본인 전용 도구로만 제한 가능한가? (상용화 유혹 차단)
3. **30p 정체성**: 옵션 II 차용 시 30p 원칙("작용만, 해석 금지") 어길 확률을 수용 가능한가?
4. **프로토타입 판정 기준**: Sonnet 제안한 "놀랐다" 이진 판정을 신뢰하는가?
5. **고고학자와의 관계**: 고고학자 Step 4-5 결과를 본 후에도 자극 엔진이 필요하다고 판단되는가?
