## 방향 전환

**"이 사람이 돼라" → "이 사람이 못 보는 걸 찾아라"**

복제본은 같은 사각지대를 가진다. 못 보는 걸 보려면 복제가 아니라 외부 관찰자가 필요하다 — 원본 데이터에 접근할 수 있되, 본인의 방어기제는 없는.

## 사용자가 진짜 원하는 것 (직접 진술)

> "나는 나의 진심을, 나의 속마음을 파헤쳐주길 원한다. 자극을 원하는 것도 그런 것이다. 내가 반응하는 곳. 평범한, 보편적 얘기가 아니라 나에 해당하는 것."
> "내가 생각하지 못한, 나의 더러운 것. 내가 생각하지 못한, 나의 정해진 것."

핵심어: **나에게만 해당하는, 내가 생각하지 못한, 더러운 것과 정해진 것.**

## 왜 이전 방식이 실패했나

1. **프롬프트 스터핑 = 검색+조립**: LLM이 데이터를 retrieval처럼 사용. 가중치 높은 것(정원이) 반복. 맥락 판별 불가.
2. **거울 왜곡**: 데이터가 최근 수개월에 편중. 수년에 걸친 가치관·세계관 미반영.
3. **분석 무해**: Claude가 사용자의 분석 프레임을 따라감. 사용자가 이미 도달한 결론을 정리해줄 뿐, 사용자가 안 간 곳을 먼저 가지 않음.
4. **보편적**: "지배-통제 패턴", "주지화 방어" — 심리학 교과서 수준 라벨링. 이상규에게만 해당하는 구체적 통찰이 아님.

### "발견" 축에 이름 — 자극 엔진

> **자극 엔진 = 외부 서사 × 사용자 기록 → 구조 매칭**

- 취향 추천 아님. "당신이 좋아할 것"이 아니라 **"당신이 이미 살고 있는 삶의 원형."**
- 불편한 거울 가능. 사용자가 싫어할 법한 결과가 최선일 수 있음.
- 낯설게 하기(defamiliarization)의 LLM 기반 기술 번역.
- 상규 직접 요구 *"나에 해당하는 것, 내가 생각하지 못한, 나의 더러운 것, 나의 정해진 것, 나의 삶 속의 통찰"*의 구조 구현.

### 나다움 공식 — NEXT_v2의 "발견" 축의 일반화

> **나다움 = 기존 나 × 새로움 = (a) × (b)**
> (a) 새로운 것에서 나를 발견
> (b) 이미 있는 나에서 새로움을 발견
> 두 축의 곱. 한쪽만 있으면 거울, 둘 다면 창문.

이 공식은 NEXT_v2가 진단한 "거울 왜곡"의 역이다. v1이 (a)축 없이 (b)축만 있어서 과장 반사가 됐다면, 자극 엔진은 (a)축을 공급한다.

### v1 실패의 구조적 재진단 — 외주 뇌 프레임

v1 실패("내가 아닌데", "뻔해")의 **기술적 원인**이 아니라 **구조적 원인**:

- v1 = **"이 사람이 돼라"** 프레임 = AI한테 **타인**이 되라는 요구 = 구조적 불가능.
- AI는 실존적으로 변하지 않음 (상규 자신이 `feedback_persuasion_contract.md`에 써둔 한계). 안 변하는 존재는 "지옥을 같이 가는" 관계가 못 된다. v1 요구와 상규 본인이 적어둔 한계가 모순이었음.
- **올바른 프레임**: AI = 상규의 **외주 뇌**. 판단은 상규가, 재료 처리·매칭·추출은 AI가. 평론가 체질과 정합.

### v2 설계 원칙

1. **"상규 재현" 목표 삭제.** 복제 목표는 거울 트랩. 폐기.
2. **"상규가 못 보는 것을 드러내는 외주 뇌" 목표 유지·강화.** NEXT_v2의 원 방향 계속.
3. **평론가 포맷으로 재작성**: v2 출력은 "이 사람이 이렇게 말했다" 흉내가 아니라 "이 자료에서 이런 구조가 보인다 / 이 패턴이 자주 반복된다 / 이 지점에서 자기 해석과 실제 행동이 갈라진다" 같은 **분석 리포트** 형식. 1인칭 복제 금지, 3인칭 관찰 채택.
4. **입력에 (a)축 추가**: 상규 본인 자료만 넣지 말고 외부 원형(문학·신화·다른 삶의 원본 기록·30p 캐릭터의 다중 해석)을 교차 입력. 이게 자극 엔진과 구조가 같음.

### 30p와의 통합 가능성

자극 엔진의 "외부 서사 DB"는 30p의 30명 캐릭터로 치환 가능. 30p 다음 실험 후보 (a) "진짜 타인 1차 데이터"의 변형 형태일 수 있음.

- **옵션 I**: 독립 제품으로 분리 (외부 서사 DB 별도 구축)
- **옵션 II**: 30p 내부 실험으로 수렴 (30명이 상규 자료 교차 해석)

판단 보류 — B 트랙 에이전트 산출물(`discoveries/2026-04-11_밤세션/02_자극엔진_*.md`)에서 양 옵션 저울질 제출. 결정은 상규.

### 자극 엔진 ≠ 고고학자

- **고고학자 (HARNESS_product)** = *사용자 기록 내부*에서 패턴 추출. 입력 = 상규 자료. 이미 MVP + PWA 완료, Step 4-5 대기.
- **자극 엔진** = *외부 서사 × 사용자 기록* 교차. 입력 = 상규 자료 + 외부 원형. 아직 설계 단계.
- 둘 다 "발견" 엔진이지만 입력 공간이 다르다. 고고학자는 (b)축만, 자극 엔진은 (a)×(b) 곱.
