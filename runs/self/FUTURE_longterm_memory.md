# 장기 기억 프로젝트 스케치

**상태**: 미착수 (2026-04-15 착안, 본격 작업은 추후)
**컨셉**: *"재미 넣어서 각 잡는 작업."* 내 머릿속(뇌)에 있는 기억을 다 문서로 빼버리는 것.

## 왜

현재 프라이머(`00_primer.md`)와 메모리 14종은 **최근 9개월 편중**. 앤두 관계(2025-06~2026-03) · 30p · 가치재판 · 송명기 미팅 · 창업 탈락이 전부 2025-06 이후.

→ 새 AI가 이상규를 읽을 때 "**최근 폭풍 속의 너**"로만 이해함. 장기 세계관 앵커 없음.

이상규 본인 지적:
> *"장기 기억은 매우 중요. 여태까지 말해준 것들은 너무 사소·단편적. 내 뇌에 있는 기억을 그냥 다 문서로 빼버려야 인생 로드맵에 의미가 있다."*

## 이게 프라이머 안 들어간 이유

- 지금 프라이머는 가볍게 시작하는 게 맞다. 장기 기억을 대충 몇 줄로 박으면 오히려 왜곡.
- 제대로 하려면 **각 잡고 한 세션** 필요. 각 잡고 하면 분량이 프라이머를 훨씬 초과.
- 이상규 본인: *"재미 넣어서 각 잡고 해야 하는 작업."* — 재미 엔진이 작동할 형식을 설계해야 지속됨.

## 내용 후보 (초안)

- **학창 시절 목표/신념**: "공부 안 하고 서울대 가기" = 고등학교 목표. 힘들었지만 잘못됐다 생각 안 함. **"멋있어 보여서"**가 동기였다는 자각.
- **오래 유지된 태도**: 아부 싫어함, 명확·직접적 소통 선호. 자기만족/효능감만으로는 안 움직이는 기질.
- **이중성**: "사회적 존중 경멸 + 극도의 존중 실천" — 이 역설이 어디서 왔는가.
- **관계사 장기축**:
  - 친구 관계 전반(군대 선임 친구 등 — 메모리 `user_social_self.md` 힌트만)
  - 가족 서사(부모·형) — 식빵=의무 의식 같은 사례들
  - 박현경 교수와의 3.5년 (특수 케이스, 왜 특수한가)
- **이상규가 자기 자신을 어떻게 봐왔는가의 변천사** — 나이별/사건별
- **프로젝트 역사**: 풀림 이전에 시도한 것들, 무엇에 빠지고 왜 떠났는가

## 방법론 후보 (재미 넣는 법)

- **가치재판 메타포 활용**: 딜레마 재판으로 풀기. 판사/변호/검사 구조가 이상규 재미 엔진과 맞음.
- **30p 시뮬과 결합**: 특정 기억을 30p 캐릭터 시나리오로 굴려보면서 이상규 자기 축 드러내기.
- **비동기 타임라인**: 시간순 나열이 아니라 "테마별 흐름"(예: "내가 멋있음이라는 단어를 어떻게 써왔나")
- **인물별 archeology**: 관계 하나당 한 문서. 박현경 교수 문서, 형 문서, 군대 선임 친구 문서, 각 친구 문서.

## 연결

- **프라이머 업데이트 트리거**: 장기 기억 작업 결과가 생기면 프라이머의 "Who"와 "v1 실패 교훈(거울 왜곡)" 섹션 보강.
- **가치재판 시스템**과 연동: 장기 기억 수집 자체를 재판 형식으로 할 수 있음(판례 누적).
- **메모리 인덱스 보강**: 현재 14종 중 장기축은 `user_philosophy.md`(2026-04-04)뿐. 최소 5~7개 장기 메모리 추가 필요.

## 주의

- **도구 만들기가 자기 이해 자체를 대체할 위험**(프라이머 섹션 6). 이 프로젝트도 같은 함정 있음.
- *"친구 관계 문서 설계"*에 빠져서 친구 관계 자체 기억을 못 꺼내는 상황 경계.
- **이상규가 직접 입으로 말해야** 하는 작업 — AI가 대신 추론 불가.
- 분량 욕심 금지. 10개 단편이 완벽한 1개보다 나음.
