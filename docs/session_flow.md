## 섹션 2 — 사용자 인터페이스 원칙 (자연어 전용)

**확정 (2026-04-09)**: 사용자는 **자연어로만** 친다. Claude 가 내부적으로 아래 의미 분류 중 하나로 해석해서 섹션 4/5/6 처리 흐름에 넘긴다. **사용자는 아래 표의 표기를 외울 필요 없음**. 표는 *Claude 전용 내부 참조*.

> 이 원칙이 깨지는 순간 = 사용자가 *"x #9 가 맞나? 폰 #9 가 맞나?"* 고민해야 할 때. 그럼 인터페이스가 실패한 것.

### 해석 원칙 (Claude 가 지킨다)

1. **완전 자연어 우선** — 사용자는 어떤 표기법도 외울 필요 없음. Claude 가 의미를 알아듣고 내부 분류로 변환
2. **모호 시 1줄 확인** — `"#9에 대해 좀 알고 싶어"` 같은 지시는 *interior / 폰 / 무의식 / 카드 / play 호출* 중 뭘 원하는지 **1줄로만** 물음. 사용자 답 → 즉시 실행. 2줄 이상 되묻지 않음
3. **변환 결과 1줄 노출 (투명성)** — Claude 가 자연어를 어떻게 해석했는지 처리 직전 1줄 박음. 예: `→ #9 interior 읽음 (play_001 장면)`. 사용자가 오해석 즉시 정정 가능. 이건 *규제가 아니라 투명성 도구* — 거슬리면 사용자 지시로 끌 수 있음
4. **복수 대상** — "9번이랑 23번 속마음" → 각 캐릭터 따로 출력
5. **play 호출 공백 채우기** — 사용자가 무대·시간 빼먹으면 Claude 가 *직전 세계 상태*에서 유추. 유추 불가면 1줄 질문
6. **한국어 우선** — 모든 응답·해석 메시지 한국어. 영어 표기는 허용하되 강요하지 않음

## 섹션 4 — play 호출 처리 흐름

**초안 근거**: `ux_design.md` 섹션 4 기본 흐름 + `code_drilldown.md` #4 (att_bandwidth 참여자 판정) + #2 (retrieve 공식, 단 *현재는 단순 append-only 유지*).

사용자가 `5분 @ 강당 "투표 발표"` 를 치면 Claude는 다음 순서로 처리한다.

### Step 1 — 참조 파일 읽기

**필수 원칙 (2026-04-10 확정)**: `seed_NNN.json` 은 **원본 전체**를 세션 시작 시점에 Read 한다. `scripts/summarize_seed.py` 요약 덤프(캐릭터당 1줄 12필드 압축) 는 사용자 훑기용만이고 **시뮬 내면 생성 컨텍스트에 들어가면 안 됨**. 근거: `.state/postmortem_vote1_summary_dump.md` (2026-04-09 vote1 메타 표기 오류 조사 결과, 실제로는 원본 기반이었지만 재발 방지 원칙으로 확립)

- `../runs/seed_001.json` — **원본 전체** (30명 4층 28표 전부). 세션 첫 play 호출 직전 Read. 세션 caching 으로 재로드 비용 낮음
- `../stages/S01_jaesu_academy.md` 또는 사용자가 지정한 무대 파일 — 공간 배치·상주 소품
- `../runs/seed_001/timeline.md` 최근 섹션 (있으면) — 직전까지의 세계 축 흐름
- `../runs/seed_001/memories/*.md` 중 **직전 play 참여자**의 최근 섹션 — 각자가 직전 장면에서 *뭘 생각했는지* 연속성 유지
- `../scenarios/S002_*.md` — 시나리오가 걸려 있으면 그 제약 조건

**시작 확인 로그**: 첫 play 직전 Claude 가 1줄로 박음. 예: `→ seed_001.json 전체 로드 (30명, body/memory/identity/korea 4층 전부 확인)`. 사용자가 이 1줄로 *요약 경유 아님*을 즉시 검증 가능

### Step 2 — 참여자 판정

무대 파일 + 사건 서술 기준으로 *그 5분간 그 공간에 있는 캐릭터*를 추린다.

- **기본 규칙**: 무대 전체에 있는 전원 (강당 = 30명 전원)
- **좁은 공간 사건**: 복도·화장실 같은 작은 공간이면 그 안의 인원만
- **이동 중**: 장면 도중 들어오거나 나가는 캐릭터는 해당 시간대만 참여자로 포함

**확정 (2026-04-09)**: **att_bandwidth 미도입**. 관찰자 철학과 방향 반대 (캐릭터 자생 메커니즘). 단순 서사 기반 판정 유지. 훔친 패턴 #4 는 참고용으로만 보존.

### Step 3 — 내면·외피 동시 생성

한 번의 Claude 호출 안에서:

1. 각 참여자의 **그 5분간 내면** (400~1200자, 수사기록 톤, 섹션 8 포맷) 생성
2. 내면이 낳는 **드러난 행동**만 뽑아 외피 타임라인 구성 (섹션 7 포맷)
3. 폰을 실제로 만진 캐릭터에 한해 `phone/<id>.md`
4. 본인 접근 불가 반응이 발생한 캐릭터에 한해 `subconscious/<id>.md`

**원칙**: 내면이 *외피의 근거*. 외피만 보고 내면을 사후에 만들어내면 합리화가 된다. 한 번에 같이 생성한다.

**금지**: 내면의 *요약*. 30명 각자가 자기 분량을 받는다. 시간 없다고 "15명만 자세히" 하는 것 금지.

### Step 4 — 파일 저장

```
runs/seed_001/
├── scenes/
│   └── play_003_D1_16h00_vote_result/
│       ├── surface.md                       ← 외피 타임라인 (섹션 7)
│       ├── interior/
│       │   ├── 01.md 02.md ... 30.md        ← 참여자 각자 내면 (섹션 8)
│       ├── phone/
│       │   ├── 09.md 23.md ...              ← 폰 만진 사람만
│       └── subconscious/
│           └── 09.md ...                    ← 접근 불가 반응 있을 때만
├── timeline.md                              ← 세계 축 누적 (surface.md append)
└── memories/
    ├── 01.md 02.md ... 30.md                ← 캐릭터 축 누적
```

**파일 명명**: `play_NNN_D{일}_HH{h}MM_{슬러그}` — `play_003_D1_16h00_vote_result`
- `NNN` = 이 시드에서 몇 번째 play인지 (0부터 연번)
- `D1_16h00` = 절대 시계 시작 시각 (콜론 대신 `h` 로 파일시스템 안전)
- 슬러그 = 사용자가 준 사건 키워드를 영문 소문자·underscore 로 (`vote_result`, `morning_coffee`). 한국어 원할 경우 한국어 (`투표_결과`) 도 OK.

### retrieve 공식에 대한 메모 (도입 X, 기록만)

- 30p 는 *관찰자(사용자) 중심*. retrieve 는 캐릭터가 자기 기억을 *자동으로* 끌어오는 매커니즘 — 관찰자 철학과 약간 어긋남
