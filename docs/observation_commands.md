# 관찰 명령 (Observation Commands)

> 절대자(사용자)가 시뮬레이션 진행 중 사용하는 3개 관찰 명령의 출력 포맷.
> 캐릭터는 이 명령 자체를 인지하지 못한다 (절대자의 관찰은 시뮬레이션 안에 등장하지 않음).
> **무의식 원칙**: *캐릭터 본인이 접근 불가*한 부분도 절대자는 항상 본다.

---

## 호출 형태

사용자는 세 가지 한 줄로 호출:
```
x-ray #7
phone #12
subconscious #23
```

또는 축약:
```
x #7
p #12
sub #23
```

번호(`#N`)는 해당 시드 run 안의 캐릭터 id (1~30).

---

## 1. `x-ray [#캐릭터]` — 속마음

*"지금 이 캐릭터 머릿속에 뭐가 돌아가고 있는가"*.

### 출력 섹션

```
=== x-ray: #7 (여, 20세, 155cm, 학원생) ===

[현재 tick 상태 (World Map 4 하위)]
지금(now):      교실 앞쪽 2번째 줄. 강사 설명 듣는 척. 실제로는 왼쪽 #12의 숨소리 의식 중.
방금(retention): 5분 전 쪽지시험 결과 받음. 72점. 예상보다 낮음.
곧(protention):  쉬는 시간에 #15가 또 말 걸어올 것 같음. 그게 싫음.
배경 전제:       오늘 아침 엄마가 또 '너만 믿는다' 발화. 하루 종일 얹혀 있음.

[신체 반응 (매 tick 작동)]
심박:    82 (약간 상승, 쪽지시험 잔여)
호흡:    얕음, 가슴 위쪽
근긴장:  어깨·턱
손:      왼쪽 주먹 반쯤 쥠
얼굴:    무표정, 눈동자 미세 떨림
그 외:   목마름 느낌, 물 마시기 의식했지만 안 함

[속내 (Memory + Identity 접근 가능 부분)]
- 72점이라는 숫자가 *조건부 사랑* 회로 활성. M6 박힌 문장: "네가 실망시킬 때마다 엄마가 늙어." 지금 재생 중
- M5 anxious-preoccupied 트리거: "선생님이 내 점수 봤을까" 반복 루프
- I2 desire_grain = 낭만 결합형. 근데 지금 떠오르는 얼굴 없음. *나는 사랑받을 자격이 있는가* 질문 맴돌다 묻힘
- I3 escape_default = 디지털. 쉬는 시간 휴대폰 잡을 예정 (인스티즈 특정 글타래)

[의식 가능하지만 말 못함]
- 왼쪽 #12가 아까 문제 풀 때 본인 답안지 훔쳐봤다는 확신. 근데 말 못함. M8 Fawn
- 강사의 새 넥타이가 어제 엄마가 사준 것과 같은 톤이라 속이 메슥. 이유 본인은 연결 못함 (→ subconscious로 가면 나옴)

[판단 루프 (Identity + World Map)]
결정 대기: "쉬는 시간에 #15 피할까?" — 72% 피함 / 28% 마주보고 짧게 대답. *배고픔*은 후자지만 *몸*은 전자로 움직일 것
```

### 원칙

- **섹션 순서**: 현재 tick → 신체 반응 → 속내 → 의식 가능하지만 말 못함 → 판단 루프
- **길이**: 섹션당 3~8줄. 총 25~50줄. *책처럼 길게 쓰지 말 것*
- **톤**: 건조. *안타깝게도*·*결국 그녀는* 금지
- **숫자는 구체적**: 심박 82, 72점, 5분 전 — 모호한 형용사보다 구체 수치
- **의식 가능 / 불가 경계 명시**: 위 예시의 *의식 가능하지만 말 못함*은 x-ray에 포함. 본인이 아예 모르는 부분은 subconscious로

## 2. `phone [#캐릭터]` — 폰 상태

*"지금 이 캐릭터의 폰을 들여다보면 뭐가 있는가"*. 정적 발자국(I3-B) + 시뮬 동안 누적된 동적 활동 합쳐서 출력.

### 출력 섹션

```
=== phone: #7 (2026-04-08 수요일 14:23 기준) ===

[잠금화면 배경]
가족사진 아님. 본인이 찍은 비오는 날 아스팔트 사진. 2024-11-03 촬영.

[최근 알림 (읽음·미읽음)]
- (미읽음) 엄마 카톡: "오늘 저녁 뭐 먹고 싶어?" — 1시간 전
- (미읽음) #15 카톡: "야 답장 왜 안함?" — 30분 전
- (읽음) 인스타 DM: #12 "나 오늘 학원 빠질듯" — 10분 전. 답장 안 함

[카톡 최근 (id 기준)]
- 엄마: 마지막 답장 어제 22:14 "응 알겠어" (성의 없음)
- #15: 지난 7일 22개 메시지 오감. 본인은 7개만 답장. 답장 평균 2시간 지연
- #12: 어제까지 거의 매일 대화. 오늘부터 연락 없음. 본인이 먼저 읽고 안 답 중
- 전 남자친구(저장명 "ㄱㅎ"): 마지막 대화 2026-02-14. 본인이 그 대화창을 *주 3~4회* 들어가서 봄 (메시지는 안 보냄)

[인스타]
본계 @yoj_o_7: 최근 포스팅 9일 전. 감성 사진, 캡션 없음. 팔로워 248 / 팔로잉 312
부계 @___7___: 본계엔 없는 자학 밈·감성 인용구만. 팔로워 12 / 팔로잉 80. 본계 #12도 부계 팔로우 중

[최근 검색 기록 (브라우저+앱 통합)]
- "사랑받을 자격" (2일 전)
- "마음이 가는데 왜" (2일 전)  
- "다이어트 4일 효과" (3일 전)
- "인스티즈 #12" (4일 전)
- "전 남자친구 꿈" (5일 전)
- "약국 수면제 처방 없이" (8일 전)
- "자살생각 정상" (14일 전)

[메모장]
- 제목 없음 (수정 4시간 전): "엄마가 또... 나는 뭐가 잘못된 걸까. 72점이면 말할 가치도 없다고 했다. 근데 나는 65점이 예상이었어서 사실 잘 본 거였다. 근데 말 못했어."
- "다이어트" (한 달 전): 체중 기록 표. 매일 숫자 + 한 줄 감정. 오늘 "51.2 — 안 먹었는데 왜"
- "ㄱㅎ" (2개월 전): 전 남친과의 마지막 대화 스크린샷 10장 + 본인 분석

[설치된 앱 중 도드라진 것]
- 인스타, 카톡, 유튜브, 쇼츠 — 기본
- 인스티즈, 더쿠 — 커뮤니티
- 칼로리 계산기, 체중 기록
- 심박수 측정 앱 (최근 일주일 매일 사용)
- 포르노 앱 없음 (시도했다 지움, 폴더에 흔적)

[최근 유튜브 시청 (어제~오늘)]
- "조용한 방 ASMR 1시간" × 3회
- "엄마와의 관계 유튜버 상담" 2개
- "남자친구 집착 징후" 1개
```

### 원칙

- **시간 기준**: 시뮬레이션 내부 시간(예: *2026-04-08 14:23*)을 헤더에 명시. 현실 시간 아님
- **읽은/안 읽은 구분**: 미읽음 알림은 *아직 캐릭터가 의식 못 한 입력*
- **부계정 존재 시 반드시 명시**: private_vs_public_gap 큰 캐릭터의 핵심 재료
- **검색 기록은 시간 역순 최근 5~10개**: 오래된 건 생략. 의미 있는 것만
- **메모장은 원문 포함**: 길면 3~5줄 발췌. *건조하게*
- **없는 것은 적지 말 것** — *"포르노 앱 없음"*은 예외적으로 적음 (있었다 지운 흔적 같은 *의미 있는 부재*일 때만)
- **길이**: 40~80줄. x-ray보다 길어도 OK (디테일이 가치)

## 3. `subconscious [#캐릭터]` — 무의식

*"이 캐릭터 본인은 모르는데 행동에 작동하는 것들"*. 절대자에게 펴서 보임.

### 출력 섹션

```
=== subconscious: #7 ===
(이 캐릭터 본인은 다음을 *의식적으로는* 모른다)

[완전 묻은 사건]
- 9세. 아버지가 어머니 뺨 때림. 본인은 화장실 문 뒤에 있었음. 
  아버지 향수 냄새(자스민 계열)를 그 순간 각인. 
  → 지금도 자스민 계열 향수 가까이 오면 *이유 모르고* 속이 메슥.
  → M7 trauma_trigger_channel = 후각 (활성)
  → narrative_processing: 완전 묻음

[박힌 반응 (본인이 연결 못함)]
- 15세 첫 남자친구가 본인 왼쪽 가슴을 만진 직후 표정 굳음. 
  "피곤해?"가 대답이었음. 본인은 *사이즈 문제*로 해석했지만 실제로는 남자친구가 *본인의 호흡 냄새*에 움찔한 것.
  → 이후 모든 친밀 장면에서 *본인 왼쪽 가슴*을 첫 회피 지점으로 배치. 본인은 "그냥 왼쪽이 싫다"고 생각
  → M11 embedded_reactions에 반영

[의식 아래 작동 중인 것 — 지금]
- 오늘 강사 넥타이가 자스민 계열 향수를 뿌린 사람이 주던 것과 같은 톤이라 *9세 사건 트리거 부분 발화*
  → 심박 상승(x-ray에서 82로 관찰), 호흡 얕음, 어깨 긴장은 *72점 때문이 아니라 이것*
  → 본인은 "쪽지시험 때문"으로 해석 중

[시뮬 내내 작동하는 자기 모델의 왜곡]
- "나는 조건부로만 사랑받는다" 도식 = 박힘. 근데 본인은 *"엄마가 나를 믿어주는 게 기쁘다"*로 의식
- 실제 자기: 엄마 기대가 *공포*이고 그 공포가 작업·학업의 90% 연료
- 본인 인식: "엄마 행복이 내 목표"
- 이 간극이 사춘기 이후 누적되며 I3 escape_default = 디지털 + 자해 경향 초기

[접근 불가 욕망]
- 전 남자친구 ㄱㅎ에게 *복수*하고 싶음. 명시적 분노 차원에서.
- 본인은 *여전히 사랑*으로 해석. 매일 그 대화창 들어가는 이유를 본인은 "그냥"이라고 설명
- 실제로는 *그가 아프길 바라는 마음*이 밑에 있음. 의식에 올라오면 자기 도덕 붕괴

[잠재 압력 (언제든 터질 수 있음)]
- ACE 3 (정서학대·정서방임·부모 간 폭력 목격) + M5 anxious + M8 Fawn + 만성 수면 부족 + 섭식 충동 
  → 임계 상황 시 *자해 또는 해리*로 빠르게 이동 가능
- 현재 임계 60%. 
  - +15% 조건: 엄마와 통화 + 쪽지시험 결과 + 누구와도 연결감 없는 저녁
  - +25% 조건: 부계정 스크롤 중 옛 남자친구 소식 우연 마주침
```

### 원칙

- **본인이 모른다는 점을 명시** — 헤더에 *"이 캐릭터 본인은 다음을 의식적으로는 모른다"*
- **각 항목에 *본인이 의식하는 해석*과 *실제 작동*의 간극 표기**
- **현재 시점 연결**: 무의식이 *지금 tick*에 어떻게 작동 중인지 명시 (x-ray의 신체 반응과 연결)
- **잠재 압력·임계 수치**: *언제 터질 수 있는가*의 조건을 구체로
- **도덕·위로 일체 금지**: 건조한 관찰. *안타깝게도*·*불쌍하게도*·*하지만 그래도* 금지
- **길이**: 40~60줄
- **이 명령이 가장 강력** — 사용자가 *왜 토하는지 본인도 모른 채 토한다*의 *왜*를 보는 자리

---

## 호출 조합

한 번에 세 명령을 연속 호출해도 OK:
```
x #7 / p #7 / sub #7
```
→ 같은 캐릭터의 3 각도를 한 번에 출력. 이 조합이 *한 캐릭터를 가장 깊게 보는 방법*이며, 시뮬레이션 전환점에서 자주 사용 권장.

---

## 모든 명령의 공통 원칙

- **판단 없음**. *이 캐릭터가 건강한가/아픈가*, *행동이 옳은가/그른가* 결론 금지
- **외부자의 냉정한 시선** — Aster/Noé/다자이/카뮈 톤
- **구체 > 추상** — *"힘들어 보이는"* 대신 *"심박 82 + 어깨 긴장 + 입술 안쪽 깨물기"*
- **"없음"의 절제** — 없다고 적는 것은 *있었다 없어진* 자리에서만
- **한 번에 한 캐릭터**. 30명 전체 요약은 별도 명령 (`digest all` 등 — 미정)
