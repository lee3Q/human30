# 저장된 장면 파일 읽기

이 도구는 사용자가 지정한 장면의 **기존 파일 하나를 읽기만** 합니다. 시뮬레이터 실행,
자연어 관찰 명령, 새 장면 생성, 캐릭터 기억 추가, 세션 저장·재개를 대신하지 않습니다.
현재 공개 저장소에 완성된 장면 예제를 제공하는 기능도 아닙니다. 테스트는 합성 임시 파일입니다.

직접 보관한 장면이 다음 구조일 때 사용합니다:

```text
my_scene/
  surface.md
  interior/09.md
  phone/09.md
  subconscious/09.md
```

```sh
python3 scripts/inspect_scene.py /path/to/my_scene surface
python3 scripts/inspect_scene.py /path/to/my_scene interior 9
python3 scripts/inspect_scene.py /path/to/my_scene phone 09
python3 scripts/inspect_scene.py /path/to/my_scene subconscious 9
```

경로는 직접 지정해야 합니다. 빈 문자열은 거부하며 명시한 `.`은 현재 폴더를 뜻합니다. 자동 검색, 최신 장면 선택, 개인 자료 폴더 탐색은 하지 않습니다.
ID는 ASCII 숫자 1~30이며 `9`와 `09`는 모두 `09.md`를 읽습니다. 세 자리 표기는 받지 않습니다.
채널 이름은 위 소문자 표기만 받습니다. `surface`에는 ID를 붙이지 않습니다.

파일이 없으면 "저장된 관찰 없음" 오류입니다. 이는 "폰을 사용하지 않았다" 또는
"무의식 반응이 없었다"는 뜻이 아닙니다. 참여자 전원의 내면이 완성됐는지, 작품의 질이
충분한지, 파일이 실제 모델에서 나왔는지는 판정하지 않습니다. 누락된 내용은 생성하지 않습니다.

## 범위와 오류

- 외부 패키지·모델·계정·네트워크 연결 없이 Python 표준 라이브러리를 사용합니다.
- 일반 UTF-8 파일을 최대 8 MiB까지 읽습니다. 자르지 않으며, 크기 초과는 오류입니다.
- 탭과 LF 줄바꿈 외의 C0/C1 제어문자, DEL, 일부 방향 제어문자가 있으면 거부합니다.
  CRLF 파일도 CR 때문에 거부합니다. 자동 변환하지 않으므로 입력 파일을 확인하세요.
- 파일 전체를 검증한 뒤 stdout에 원래 바이트를 씁니다. 검증 실패는 stderr와 종료 코드 2입니다.
  출력 파이프가 닫히는 등 출력 중 실패는 코드 1이며, 이미 전달된 바이트는 회수할 수 없습니다.
- POSIX의 디렉터리 상대 열기·심볼릭 링크 거부 기능이 필요합니다. 미지원 환경은 거부합니다.
  경로의 각 구성 요소와 마지막 파일의 심볼릭 링크를 거부하며 `..`도 받지 않습니다.
- 일반 파일만 읽습니다. FIFO·장치·디렉터리를 내용 파일로 읽지 않습니다.
- 이것은 보안 격리나 출처 검증이 아닙니다. 하드 링크, 공격자가 제어하는 파일시스템,
  읽는 도중 다른 프로세스가 바꾸는 내용에 대한 일관된 스냅샷을 보장하지 않습니다.
- 이 도구는 파일이나 기록을 생성·수정·삭제하지 않지만 OS의 읽기 시각(atime)은 바뀔 수 있습니다.
  영구 보관·삭제·관찰 기록 정책은 도입하지 않습니다.

사용자가 직접 선택한 파일을 읽는 도구입니다. 출력할 터미널이나 로그가 공유되는 환경에서는
개인 자료를 선택하지 마세요. 실제 인물의 심리를 판정하거나 저장 내용의 진실성을 증명하지 않습니다.
