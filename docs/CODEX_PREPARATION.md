# Codex로 Human30 실행 준비하기

이 안내는 Codex에 제공할 입력을 준비합니다. 실제 모델 실행·품질 검증은 하지 않았습니다.
별도 `product/` 대화 통계 웹앱이나 네 축 비교 실험을 30인 시뮬레이터로 바꾸는 기능도 아닙니다.

## 1. 무엇을 보내는지 먼저 보기

Python 표준 라이브러리만 사용합니다. 로그인·설치·모델 호출·출력 파일 저장을 하지 않습니다.
저장소 루트에서:

```sh
python3 scripts/prepare_codex.py --summary
python3 scripts/prepare_codex.py
```

첫 명령은 경로·크기·SHA-256과 사건 제안만, 둘째는 원문을 포함한 JSON을 stdout에 출력합니다.
경로는 다음 세 파일로 고정됩니다:

- `runs/seed_001.json`: 포함된 가상 성인 30명 전체
- `docs/PORTABLE_PROMPT.md`: 기존 원작 프롬프트, 변경하지 않음
- `stages/S01_jaesu_academy.md`: 기존 무대, 변경하지 않음

제안 사건은 D1 08:30~08:35, 30명 전원의 평범한 아침 자습 준비입니다. 새 압력 시나리오는 없습니다.
`.state`, `runs/self`, `runs/sanggyu_exp`, 개인 대화·이력·인증정보는 읽지 않습니다.
단, 이 세 파일 자체를 사용자가 편집했다면 내용도 달라집니다. 해시는 출처나 무해함을 증명하지
않습니다. 전송 전 내용을 확인하세요. 파일 크기는 토큰 수나 예상 비용이 아닙니다.

## 2. ChatGPT 로그인으로 쓰는 Codex

공식 [인증 안내](https://developers.openai.com/codex/auth)를 따라 본인 계정으로 로그인합니다.
Codex cloud는 ChatGPT 로그인이 필요합니다. 일반 ChatGPT 채팅에 붙여 넣은 결과를 Codex 실행으로
세지 마세요. 현재 계정의 Codex 접근·사용량·추가 크레딧 설정을 먼저 확인해야 합니다.

위 준비 JSON을 검토한 뒤 본인이 선택한 Codex 입력 경로로 제공합니다. 저장소 전체 연결을
대신하지 않습니다. cloud가 저장소나 환경 연결을 요구하면 그 범위를 따로 확인하세요.
기존 개인 저장소 전체를 연결하라는 뜻이 아닙니다. 본 도구는 cloud 환경을 만들거나 업로드하지 않습니다.

## 3. 내 컴퓨터의 공식 Codex CLI로 쓰기

로컬은 **클라이언트가 내 컴퓨터에서 실행된다**는 뜻입니다. 오프라인 모델이나 무료 실행이 아닙니다.
CLI 설치·로그인은 공식 안내를 따르세요. 이 저장소의 준비 도구가 설치하거나 인증을 대신하지 않습니다.
현재 CLI의 `codex --help`와 `codex exec --help`를 먼저 확인하세요.

기존 로그인과 사용량·비용을 확인하고, 입력을 검토해 실제 전송하기로 정한 뒤에만:

```sh
bundle=$(python3 scripts/prepare_codex.py) &&
  printf '%s\n' "$bundle" | codex exec --ephemeral --sandbox read-only --skip-git-repo-check -
```

입력 준비가 실패하면 `&&` 뒤의 실행은 시작하지 않습니다. `bundle`은 현재 셸 메모리에 남을 수 있습니다.
이 마지막 명령은 **실제 모델에 입력을 보내고 사용량을 소비할 수 있습니다**. 준비 검사 명령이 아닙니다.
공식 [비대화형 실행 안내](https://developers.openai.com/codex/noninteractive.md)의 stdin 경로를
사용합니다. 구버전 CLI에서 옵션이 다르면 자동 우회하거나 권한을 넓히지 말고 공식 도움말과 대조하세요.
기존 config의 모델·제공자·MCP·도구 설정이 영향을 줄 수 있습니다. 개인 파일이 있는 작업 폴더에서
무심코 실행하지 마세요. read-only는 파일 쓰기 제한이지 읽을 수 있는 개인 자료의 완전한 격리가 아닙니다.

`--ephemeral`은 로컬 세션 rollout 파일을 남기지 않는 옵션이지 제공자 보관·로그·셸 기록·
임시 파일·외부 도구까지 모두 삭제한다는 보장이 아닙니다. 별도 영구 보관·삭제 규칙은 도입하지 않습니다.
API 키 로그인은 ChatGPT 포함 사용량 대신 별도 API 요금이 적용될 수 있습니다. 자동 전환·크레딧
구매·새 키 생성은 하지 마세요. 인증 파일이나 토큰을 채팅·저장소에 붙여 넣지 마세요.

## 결과를 무엇으로 판단하나

- 실제 모델 응답과 합성 테스트를 구분합니다. 거부·잘림·누락을 완료로 세지 않습니다.
- 전원 참여 장면은 30명 각각의 내면과 외피의 연결을 확인합니다. 일부 인물만 자세히 쓰거나
  요약한 응답으로 전원 실행을 주장하지 않습니다.
- 폰·무의식의 저장 관찰 누락은 "활동 없음"을 뜻하지 않습니다. 조회하면서 새로 생성하지 않습니다.
- 이 준비 경로는 완성된 장면 저장·재개·자동 파일 분리 기능을 제공하지 않습니다. 모델이
  "저장했다"고 말하는 것과 실제 파일이 존재하는 것은 다릅니다.
- 실제로 보관한 장면 파일은 [읽기 전용 조회 도구](STORED_SCENE_READER.md)로 읽을 수 있습니다.
  보관 방식·새 writer·실패 기록·삭제 정책은 이 안내에서 정하지 않습니다.

공식 [현재 가격·사용량 안내](https://learn.chatgpt.com/docs/pricing)를 참고하되,
본인의 계정·구독·잔량·추가 비용은 따로 확인하세요. 준비 성공은 특정 모델의 작품 품질,
30인 출력 용량, 원작 지시와 제공자 정책의 호환성이나 실제 인물 예측을 증명하지 않습니다.
