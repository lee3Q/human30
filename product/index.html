모든 해석은 고정된 동작 확인용 예시입니다. 개인 분석이 아닙니다. 제공된 합성 CSV만 사용할 수 있습니다.

카톡 분석

카톡을 넣으면, 네가 몰랐던 너를 숫자로 보여준다.

일반 모드 데이터 안내 (합성 데모는 외부 AI를 호출하지 않습니다)
  • CSV는 이 페이지를 제공하는 서버로 전송되어 메모리에서 분석됩니다. 기본 실행 서버는 이 기기(localhost)이며, 앱은 업로드 파일을 디스크에 저장하지 않습니다.
  • 발견 생성 시 참가자 이름과 통계가 Anthropic API로 전송됩니다. 반박을 적으면 그 내용도 후속 해석과 깊은 질문 생성에 전송됩니다. 원문 전체를 API에 보내는 기능은 없습니다.
  • 마지막 깊은 질문의 답변은 서버 메모리와 내보내기 결과에 포함되며, 현재 이 답변을 AI로 보내지는 않습니다.
  • 세션 완료나 페이지 닫기로 서버 메모리가 즉시 지워지지 않습니다. 생성 후 1시간이 지난 세션은 다음 CSV 업로드 시 정리되며, 서버 프로세스를 종료하면 메모리가 사라집니다.
  • 내려받은 결과 파일은 내 기기에 남습니다. AI 제공자의 보관·삭제 정책은 별도로 확인해야 합니다.
