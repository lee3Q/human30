# 카톡 통계 → 발견 → 반박 웹앱

`product/`는 저장소의 30명 캐릭터 시뮬레이터와 별개인 실험용 웹앱입니다.
CSV 통계를 확인하고, 해석에 동의하거나 반박하고, 마지막 답변을 결과 파일로 내보냅니다.
사람의 속마음·성격·관계를 판정하는 도구나 검증된 상담 서비스가 아닙니다.

## 무료 합성 데모

저장소 루트에서 Python 3.11 이상으로 실행합니다. 이 웹앱 경로는 표준 라이브러리만 사용합니다.
`uv sync`나 모델 다운로드는 필요하지 않습니다.

```sh
python3 product/server.py --demo --port 8000
```

http://localhost:8000 에서 "가상 대화로 시작"을 누르세요. `demo.csv`의 가상 인물 2명,
메시지 4개만 사용합니다. 발견 1개에 동의·반박·건너뛰기를 시험한 뒤 마지막 질문에
답하고 "세션 마치기" 다음 "내 기기에 저장"을 눌러 결과를 내려받을 수 있습니다. 결과 JSON에 `demo: true`가
표시됩니다. 여러 경로를 시험하려면 페이지를 새로 열고 다시 시작하세요.

- 모든 발견·후속 응답·마지막 질문은 고정된 합성 문장입니다. 통계로부터 추론한 결과가 아닙니다.
- API 키가 환경에 있어도 `--demo`에서는 외부 AI 요청을 하지 않습니다.
- 제공된 합성 CSV 외 업로드는 거부합니다. 파일은 거부 검사 전에 로컬 서버로 전송되므로 개인 대화는 선택하지 마세요.
- 데모는 오프라인 설치 앱이 아닙니다. 실행 중인 로컬 서버가 필요합니다.
- 종료하려면 터미널에서 Ctrl+C를 누릅니다. 내려받은 파일은 기기에 남습니다.

## 일반 모드

```sh
python3 product/server.py --port 8000
```

실제 AI 해석에는 서버 환경의 `ANTHROPIC_API_KEY`가 필요합니다. 키가 없으면 합성 데모로
자동 전환하지 않습니다. 외부 AI 호출은 유료일 수 있습니다. 제공자 계정·비용·보관 정책을
직접 확인한 뒤 사용하세요. 키를 URL·명령 인자·소스 코드에 넣지 마세요.

일반 모드는 CSV를 로컬 서버 메모리로 전송해 통계를 계산합니다. 발견 생성 시 참가자 이름과
통계가 Anthropic API로 전송되고 반박 내용도 후속 응답과 마지막 질문 생성에 전송됩니다.
마지막 답변은 메모리와 내보내기에 포함되지만 현재 AI로 전송하지 않습니다. 세션 완료나
페이지 닫기로 메모리가 즉시 삭제되지는 않습니다. 생성 후 1시간이 지난 세션은 다음 CSV
업로드 때 정리되며 서버 종료 시 메모리가 사라집니다. 결과 파일은 별도로 직접 관리해야 합니다.

서버는 127.0.0.1에 바인딩됩니다. 인증·HTTPS·공개 서비스용 운영 체계를 갖춘 배포가 아닙니다.
타인의 대화는 동의 없이 올리지 마세요. 합성 데모의 성공은 실제 AI 품질·보안·임상 효과나
배포 준비 완료를 입증하지 않습니다.
