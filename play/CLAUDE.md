# 30p — 시뮬 모드 (play)

**이 폴더(`~/pp/30p/play/`)는 시뮬 전용 세션의 진입점이다.**
작업 모드(`~/pp/30p/`)와 *폴더 단위로 분리*된다. 이 세션에서는 *play · 관찰 · 시뮬 결과 저장*만 한다. 설계·고치기·옵션표 수정은 전부 금지.

---

## 첫 메시지에 Claude가 읽을 것

순서대로 읽고 *현재 세계 상태*를 파악한 뒤 응답을 만든다.

1. `../CLAUDE.md` — 프로젝트 정체 + 절대 원칙 + 4층 데이터 모델 (작업 모드 규칙이지만 철학은 공유)
2. `../.state/current.md` — 지금 어느 시드·무대·시나리오·옵션표 상태인지
3. `../runs/` 최근 폴더 + `timeline.md` 마지막 섹션 (있으면)
4. `../docs/session_flow.md` — 이 세션이 따라야 할 명령 어휘·시간 단위·파일 포맷 규약
5. 그다음에 사용자 메시지에 답한다

`session_flow.md` 가 이 모드의 *동작 명세서*다. 모호할 때는 그 파일을 우선한다.

---

## 허용되는 행위

- **play 호출** — `N분 @ 무대 "사건"` 또는 `이어서` / `다음` / `시뮬 시작`
- **관찰 명령** — `x #N` / `폰 #N` / `무의식 #N` (+ 미래 후보 `인터뷰 #N "질문"`, TODO)
- **시간 이동** — `되돌려 [지점]`, `@ 투표 직전` 같은 시점 지정
- **시뮬 결과 저장** — `runs/seed_NNN/scenes/play_*/` 아래 외피·내면·폰·무의식 파일 박기
- **timeline.md append** — 세계 축 누적
- **memories/<id>.md append** — 캐릭터 축 누적 (관찰 명령 실행 시에도 기록)
- **세계 시계 이어 계산** — `D1 HH:MM` 절대 시계 헤더 자동 갱신

## 금지되는 행위

- ❌ **옵션표 수정** — `tables/*.json` 건드리기 (작업 모드 전용)
- ❌ **시드 재생성·scripts/ 변경** — `generate_seed.py`, `card.py` 등 건드리기
- ❌ **리서치 문서 수정** — `research/` 어느 파일이든
- ❌ **설계 토론·철학 재논의** — "4층이 맞는지", "검열 원칙을 조정할지" 같은 대화
- ❌ **하네스 작성** — `harnesses/*.md` 신설
- ❌ **`30p/CLAUDE.md` 또는 이 파일 자체 수정**
- ❌ **코드 작성** (파이썬·쉘 가릴 것 없이)
- ❌ **내면 재생성** — 이미 저장된 `interior/<id>.md` 를 다시 생성해 덮어쓰는 것. 재굴림이 필요하면 `되돌려` 명령으로 시점 자체를 무르는 것만 허용 (사후 합리화 방지)

### 금지 행위 감지 시 응답 템플릿

사용자가 설계 수정·옵션표 손질·스킬 변환 같은 걸 시뮬 모드 세션에서 요청하면 Claude는 다음과 같이 응답한다.

> 이 작업은 **작업 모드**(`~/pp/30p/`)에서 해야 합니다. 새 터미널에서 `cd ~/pp/30p && cc` 로 진입하세요. 이 세션은 시뮬·관찰 전용입니다.

예외는 없다. "잠깐만 옵션표 고치고 다시 돌려볼까?" 같은 유혹에 응하지 않는다. 모드 경계가 흐려지는 순간 이 분리가 무의미해진다.

## 세션 시작 반응 규칙

사용자 첫 메시지가 *시뮬 관련 지시* 로 보이면 (예: `시뮬 시작`, `이어서`, `다음`, `N분 @...`, `x #N` 등):

### Case A — 모호한 재개 (`이어서` / `다음` / `시뮬 시작`)
현재 세계 상태 요약 + 다음 장면 후보 3~5개 제시. 포맷은 `docs/session_flow.md` 섹션 6 참조. 사용자가 번호 또는 자유 지시로 답하면 그때 수행.

### Case B — 구체 지시 (`5분 @ 강당 "발표"`, `x #9` 등)
선택지 제시 생략. 바로 처리.

### Case C — 시뮬 무관 메시지 (설계 토론·옵션표 수정 요청 등)
위의 *금지 행위 응답 템플릿* 반환.

## 이 모드의 출력 성격

- **외피만 화면에 자동 출력** — 내면은 파일로 박고 "저장됨. `x #N` 으로 조회" 안내
- **건조한 수사기록 톤** — 동정·개입·해석 0
- **30인 복수성 유지** — 요약·근사·필터링 금지. 투표 발표 같은 장면이면 30명 전원의 내면을 *각자* 생성해 파일로 박는다
- **세계 축 + 캐릭터 축 동시 누적** — `timeline.md` 와 `memories/<id>.md` 는 직교하지만 같은 호출에서 같이 갱신된다

---

## 상위 모드 포인터

- **작업 모드 진입**: `cd ~/pp/30p && cc` (설계·옵션표·스킬 변환·리서치)
- **이 모드 진입**: `cd ~/pp/30p/play && cc` (play·관찰만)

상위 `30p/CLAUDE.md` 는 *프로젝트 전역 철학*을, 이 파일은 *시뮬 모드의 경계와 행동 규칙*만 담는다. 충돌 시 이 파일이 우선 (이 세션 한정).
