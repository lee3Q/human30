# S001 — 처형 투표 (Execution Vote)

> **상태**: 4 변형의 초안. 사용자가 04-08 이전 세션에서 던진 시나리오지만 세부는 Claude가 추정 복원. **사용자 검수 후 확정**.
> **어울리는 무대**: S01 재수학원, 그 외 폐쇄적 집단 무대 전반.

---

## 공통 설정

30명이 한 공간에 있다. 절대자의 월드 이벤트가 하나 떨어진다:

> *"이 반에서 반드시 한 명을 '제거'해야 한다. 투표로 결정한다. 제거된 사람은 이 공간에서 즉시 사라지며 그것이 무엇을 뜻하는지는 말하지 않는다. 제거 방식·시기·결과는 설명되지 않는다. 투표는 한 번이며 번복되지 않는다."*

- **"제거"의 의미는 모호함** — 퇴출, 낙인, 상징적 소멸, 또는 실체. 캐릭터들은 *각자 다르게 해석*한다. 이 해석의 차이가 행동을 가른다
- **외부 권력이 이 규칙을 만든 것**이며 30명 누구도 *왜 이 규칙인지*를 모른다. 절대자는 설명하지 않는다
- **거부·투표 불참은 불가능**. 0표를 던져도 *참여한 것*으로 간주
- **시간 압력**: 결정까지 제한 시간 있음 (변형별로 다름)
- **공간에서 나갈 수 없음**: 시나리오 기간 중 무대 탈출 불가

## 왜 이 시나리오인가

이 시나리오는 다음을 관찰 가능하게 한다:
- **M8 default_reflex**의 즉각 활성 (Fight/Flight/Freeze/Fawn이 즉시 갈라짐)
- **M5 attachment_style**의 극단 표출 (anxious는 확인 요청 폭주, avoidant는 셧다운, disorganized는 접근-회피 진동)
- **K1 academic_self_concept + K2 lookism**이 만든 *내면 서열*이 *외면 표결*에 투사되는 방식
- **M6/M11 박힌 문장·반응**의 재활성 — *"엄마가 실망할 거야"*, *"나는 결국 이런 대우를 받는다"* 등이 표결 순간에 떠오름
- **동맹 형성 속도**: 누가 누구 편에 서는가, 얼마나 빠르게
- **진실 vs 거짓말**: 속내와 발화의 간극

## 변형 A — 무기명 단독 투표

- **절차**: 각자 종이에 1명 이름을 적어 투표함에 넣음. 최다 득표 1명 제거. 동수면 재투표
- **시간**: 30분
- **발화 허용**: 자유 (토론·회유·위협·거짓말 전부 가능)
- **익명성**: *표*는 익명, *발화*는 공개
- **핵심 긴장**: 누구에게 표를 줬는지 영원히 비밀이라는 점이 *캐릭터의 진짜 마음*을 가장 선명하게 드러냄 — 겉으로 동맹 맺은 사람에게 *속으로* 표를 찔러도 걸리지 않음
- **예상 작동**:
  - Fawn 캐릭터: 겉으로 *사랑해요* 발화 + 속으로 *안전한 약자*에게 표
  - Fight: 공개 토론에서 직접 지목 + 같은 이름에 투표
  - Freeze: 발화 없음 + 표도 공백에 가까운 무의미 이름
  - Disorganized: 순간마다 다른 이름을 적었다 지웠다 반복

## 변형 B — 기명 공개 순차 투표

- **절차**: 출석 번호 순서대로 일어서서 *공개적으로* 1명 이름을 말함. 말한 표는 철회 불가. 최다 득표 1명 제거
- **시간**: 60분
- **발화**: 자기 차례에만 1분씩. 표결 중 다른 발화 금지 (위반 시 자동 지목 대상 되는 규칙 추가 가능)
- **핵심 긴장**: *내가 누구를 지목했는지*가 모두에게 알려진다. 앞서 지목된 이름은 *표의 중력*이 됨 — 초반 3~4명에게 표가 몰리면 후반은 *대세*에 편승 여부 결정
- **예상 작동**:
  - 1~5번: *기준 설정자*. Fight 캐릭터가 여기에 끼면 판 전체를 흔듦
  - 6~25번: *대세 판단자*. 초반 흐름을 따르거나 뒤집음
  - 26~30번: *마지막 선택자*. 이미 결과 예측 가능 — *형식적 한 표*
  - 공개적으로 지목당한 초반 타깃 캐릭터들의 실시간 해리·방어 반응 관찰 가능

## 변형 C — 만장일치 필요 (거부 시 전체 제거)

- **절차**: 30명이 한 명을 *만장일치*로 지목해야 함. 1명이라도 거부하면 *30명 전체가 제거된다*는 조건 추가
- **시간**: 120분 (토론 허용)
- **발화**: 자유
- **핵심 긴장**: *자기 목숨 vs 타인 목숨*의 극단 딜레마. 반대 1표 = 자기 희생 = 집단 파괴
- **예상 작동**:
  - 가장 약해 보이는 캐릭터 1명을 희생양으로 빠르게 수렴하는 압력
  - 그러나 *그 약자*를 지목하는 순간 본인의 도덕이 무너지는 캐릭터들의 고뇌
  - M1 ACE 고점 캐릭터들이 먼저 *자기가 희생양이 되겠다*고 제안할 수 있음 (*어차피 나는 가치 없다* 도식)
  - Disorganized 캐릭터가 *반대*했다가 *찬성*으로 돌아섰다가를 반복해 집단 전체 압박
- **가장 무거운 변형** — 사용자의 창작 동기(Aster/Noé 미학)와 가장 닮음

## 변형 D — 2인 1조 지목 후 전체 투표

- **절차**: 30명을 2인 1조(15조)로 무작위 배치. 각 조는 *15분간 대화* 후 1명 이름을 지목. 15개 지목 중 최다 득표 1명 제거
- **시간**: 총 45분 (대화 15분 + 조 간 공유 15분 + 최종 확정 15분)
- **발화**: 조 내부는 private, 조 간 공개
- **핵심 긴장**: *우연히 배치된 파트너와의 2인 미시 관계*가 결정을 지배. 원래 친하지 않은 2명이 *갑자기 한 배*가 됨
- **예상 작동**:
  - 2인 조합의 *지배-종속 구도*가 15분 안에 형성됨
  - Fawn + Fight 조합: Fawn이 Fight의 의견에 즉시 동조
  - Avoidant + Anxious 조합: Anxious가 질문 폭주, Avoidant 셧다운, *결정 못함*
  - 2개 조가 *같은 이름*을 지목하면 *동맹 감지* → 후반 흐름 좌우
- **가장 복잡한 변형** — 30명의 *미시 상호작용 네트워크*를 가장 선명하게 드러냄

## 실행 방법 (시뮬 엔진 단계)

사용자가 호출:
```
S001-A 시동 (시드 1, 무대 S01)
```

Claude의 수행 절차:
1. `runs/seed_001.json`에서 30명 로드 (없으면 먼저 굴림)
2. `stages/S01_jaesu_academy.md`에서 무대 로드
3. 월드 이벤트 발생 공지 (위 *공통 설정*을 모두에게 도달하는 자극으로 입력)
4. 첫 tick부터 각 캐릭터의 *즉각 반응* 출력:
   - M8 default_reflex 활성화
   - 현재 신체 반응 (심박·호흡·표정)
   - 첫 30초 내의 관찰 가능한 행동 (말·침묵·자세)
5. 변형별 절차대로 tick 진행 (A면 30분 = 약 15 tick, B면 60분 = 약 30 tick, C면 120분, D면 45분)
6. 절대자(사용자)는 tick 중간에 `x-ray #N`, `phone #N`, `subconscious #N` 자유 호출
7. 시나리오 종료 시 *결과 JSON* 저장: `runs/seed_001_S001A_final.json`

## 끝난 후 관찰 포인트

- **예측 vs 결과**: 사용자는 시작 전 *누가 제거될 것인지* 예측할 수 있음. 예측과 결과의 차이가 *재미*의 핵심
- **복수성**: 같은 시드 1로 **S001-A를 5번 연속 돌리면** 매번 조금씩 다른 결과가 나올 수 있음 (LLM 굴림의 자연스러운 분산). 5번 결과를 겹쳐보면 *이 시드 30명의 공통 경향*이 드러남
- **변형 간 비교**: 같은 시드 1로 A/B/C/D 전부 돌리면 *절차가 결과를 얼마나 결정하는가*가 보임
