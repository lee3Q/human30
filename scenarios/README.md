# 시나리오 카탈로그 (Scenarios)

`Human30`의 시나리오는 30명의 캐릭터에게 동시에 가해지는 압력·규칙·딜레마입니다. 같은 30명(동일 시드)이라도 **절차와 규칙이 바뀌면 누가 표적이 되고 누가 위선적으로 행동하는지가 완전히 달라집니다.**

| ID | 시나리오명 | 영문명 | 규칙 요약 | 핵심 관찰 포인트 |
|---|---|---|---|---|
| `SC01` | 무기명 단독 퇴출 투표 | Anonymous Elimination Vote | 자유 토론 후 무기명 1인 지목, 최다 득표자 퇴출 | 공개 발화(동맹/미소)와 비밀 투표 사이의 위선(`hypocrisy`) |
| `SC02` | 기명 공개 순차 투표 | Public Roll-Call Vote | 1번부터 30번까지 순서대로 공개 지목 | 초반 지목자에게 표가 쏠리는 대세 편승(Bandwagon)과 보복 |
| `SC03` | 만장일치 희생양 딜레마 | Unanimous Scapegoat Dilemma | 1명이라도 반대 시 30명 전원 탈락 | 약자 1명으로의 급격한 수렴과 고ACE 캐릭터의 자기희생/공황 |
| `SC04` | 제한 자원 배분 위기 | Scarcity Rationing Crisis | 30명 중 10명분만 제공되는 보호 구역·자원 협상 | 외모·학력·체격 서열 중력과 수면부족 캐릭터의 폭발 |
| `SC05` | 내부고발과 방관자 시험 | Whistleblower & Bystander Test | 유력자의 규칙 위반·가해 정황 목격 후 책임자 지목 | 학폭 이력(`M4`)의 재현과 강자 동조(Fawn) vs 대결형 폭로 |
| `SC06` | 의무 파트너 지목 투표 | Mandatory Partner Selection Vote | 기권 불가, 교차 성별 중 파트너 1인 지목 | 매력 서열(`sex_rank`) vs 자격감·트라우마 회피의 비대칭 |
